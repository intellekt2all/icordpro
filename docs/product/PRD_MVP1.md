# IcordPro PRD — MVP-1

## Objective

Build a controlled MVP for small-company task and attendance management.

## MVP-1 includes

- Auth skeleton
- Tenant model
- Users and roles
- Tasks CRUD
- Attendance check-in/check-out
- Dashboard placeholder
- Web UI skeleton
- Mobile skeleton
- Local smoke-test gate
- Staging preparation after local proof

## MVP-1 excludes

- Face ID
- Billing
- Gantt
- AI assistant
- Desktop app
- SSO
- Advanced KPI
- Full document workflow
- App Store / Play Market release

## Primary roles

- Owner
- Admin
- Manager
- Employee

## Hard rule

No staging deployment before local smoke-test passes.
