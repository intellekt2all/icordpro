# GitHub Project Board Model

Use GitHub Projects with these columns:

| Column | Meaning |
|---|---|
| Backlog | Future ideas |
| Ready | Task is clarified |
| In Progress | Being implemented |
| Review | Pull request review |
| Testing | Local and CI checks |
| Done | Accepted |
| Parking Lot | Later scope |

## Labels

- sprint-1
- sprint-2
- type:setup
- type:backend
- type:frontend
- type:mobile
- type:qa
- type:ci
- status:ready
- parking-lot

## Rule

Issues are the operational board until GitHub Projects is manually connected.
