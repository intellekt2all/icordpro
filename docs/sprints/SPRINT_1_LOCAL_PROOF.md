# Sprint 1 — Local Proof

## Goal

Prove that the repository can run locally before deploy work starts.

## Tasks

1. Repo and environment
2. Docker and PostgreSQL
3. DB migration placeholder
4. API health endpoint
5. Web starter
6. Smoke test
7. CI pipeline
8. Review

## Acceptance criteria

- pnpm install works
- docker compose starts local DB
- pnpm db:migrate works
- pnpm dev starts API
- pnpm smoke:test passes
- GitHub Actions passes on PR

## Stop rule

Do not start Sprint 2 until Sprint 1 local proof is verified.
