# Sprint 2 — Protected Routes and Refresh Flow

## Goal

Add real protected routes after Sprint 1 passes.

## Scope

- Web route guard
- Login redirect logic
- Logout
- API unauthorized handling
- Refresh flow design
- Mobile secure storage decision

## Acceptance criteria

- Dashboard is unavailable without valid session
- Login page redirects when session exists
- API unauthorized response clears session
- Typecheck passes
- Build passes

## Exclusions

- Billing
- Face ID
- AI
- Gantt
- App Store or Play Market release
