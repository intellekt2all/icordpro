# IcordPro Design System — MVP

## Design principles

- Business SaaS first
- Clear hierarchy
- Fast daily usage
- Mobile attendance flow must be simple
- Avoid decorative complexity in MVP

## Components

- Button: primary, secondary, danger
- Input: default, error, disabled
- Card: stat, table, action
- Sidebar: expanded, mobile hidden
- Table: default, loading, empty
- Modal: confirm, form
- Badge: status, role, priority
- Bottom Nav: mobile tabs

## Required pages

- Landing
- Login
- Register
- Dashboard
- Tasks
- Attendance
- Users
- Settings
- Mobile Login
- Mobile Attendance
- Mobile Tasks

## Handoff rule

Design tokens first. Pages second. Components must not be duplicated per screen.
